# Credimi design assets

`src/css/style.css` is the unchanged runtime copy of `HITL/style.css` (SHA-256 `ff452337f866cae1060057a8c417752b5a9767f59b748c9c7cde509c638387c7`). The regular logo is `src/assets/credimi_logo.svg` (SHA-256 `031885760a9165e9d8d49eab45baca30ba5ed8dd1fbf0b4699fba2de5dc4feac`) and is used on light surfaces and as `/assets/credimi_logo.svg` favicon. The negative logo is `src/assets/credimi_logo_negative.svg` (SHA-256 `32df33f9f5ffa696d452e1f65f5d6738b920415c5114db4b010af1f997a8cb3a`) and is used only in the dark footer.

`css/app.css` loads after the shared foundation and is limited to Atlas-specific layout and composition: the brand hero and stack visual, status pills (glyph plus label, never colour alone), the radar timeline, and the labelled Credimi promotion blocks (`src/_includes/components/credimi.njk`). It adds dark-surface button variants as new classes and does not restyle shared components. Update an HITL input intentionally, then synchronize its runtime copy.

`src/assets/og-cover.png` (1280×640, SHA-256 `132fda129fc9ea3a1a86c04c1eee5512554dae7fc56dde5df0d6de6a283527b2`) is the social cover used by `og:image` and `twitter:image` on every page and shown at the top of `README.md`. It is generated from `docs/og-cover.html` — open that file in a browser at a 1280×640 viewport and capture the viewport — using the bundled Inter and Source Code Pro fonts and the unmodified negative logo on the dark brand gradient. GitHub's social preview upload is manual (Settings → Social preview); use the same PNG so the repository card and shared links match.
